# Rust 版への移行

バージョン 0.2.0 で、Python / Shapely / NumPy / Pillow / Tkinter / PyInstaller を使う構成から Rust の Cargo プロジェクトへ移行しました。Python を実行する補助プロセスはありません。

| 機能 | Rust の実装 |
| --- | --- |
| RS-274X、極性、円弧、アパーチャマクロ | `src/parser.rs`、`src/geometry.rs` |
| 銅箔の和集合・差集合、穴の保持 | `src/overlay.rs` |
| ギャップ測定、コーナー除外、近傍集約 | `src/detector.rs` |
| 入力の選択、層の並列検査、進捗通知 | `src/engine.rs` |
| CLI と既存オプション・終了コード | `src/main.rs` |
| ファイル・フォルダー選択 GUI | `src/gui.rs`、`src/bin/gui.rs` |
| PNG / HTML / CSV / JSON | `src/report.rs` |

GUI は検査対象を実ファイルの一覧に展開し、重複追加と個別の除外に対応します。検査はバックグラウンドで実行し、完了層数の進捗バー、活動表示、経過時間を別々に更新します。完了後はローカルの HTML を開けます。

しきい値との比較は従来どおり `gap_mm < threshold_mm - tolerance_mm` です。JSON のスキーマバージョン 1、CSV の UTF-8 BOM、画像の相対リンク、CLI の終了コード 0 / 1 / 2 を維持しています。Python モジュールを import する API は廃止しました。

形状演算には純 Rust の Clipper2 を使い、0.0000000001 mm の固定格子で整数演算します。絶対座標 ±100000 mm を超える形状はエラーにします。等幅ギャップが連続すると、微小な数値差により近傍集約後の代表座標や件数が旧版と異なる場合があります。

## 0.2.0 の検証（2026-11-02）

- 移植前の Python 版の既存 32 テストが合格することを確認しました。
- Rust 版は 23 テストに加え、移植前に保存した合成ガーバー 19 ケースの面積・最小ギャップ・検出範囲を照合しています。
- GUI の描画、入力検証、バックグラウンド検査から結果表示まで、失敗時の進捗保持をネイティブウィンドウなしで検証しました。
- Altium の `MIN-778-03.GTL` / `MIN-778-03.GP1`、KiCad の `kb-CuTop.gbr` を 0.1 mm で検査し、旧版・新版とも違反 0 件でした。形状演算の丸めで発生した偽スリットは固定格子への変更で解消し、縮約した接続形状を回帰テストに追加しました。
- 全体・拡大 PNG を目視で確認しました。
- Windows 用 GUI / CLI の release ビルド、整形チェック、Clippy の警告なしチェックを実施しました。

GUI の実画面確認は、コンピューター操作ツールが対象アプリの起動を許可しなかったため未実施です。

## 0.2.1 の変更

- 白い背景と濃い文字・境界線に変更し、日本語フォントと文字サイズを調整しました。
- フォルダー検索を下位階層まで広げ、フォルダー内の ZIP も検索します。
- 「ZIPを追加」を追加しました。無圧縮・Deflate 圧縮の ZIP を展開せず読み取り、内部の下位階層を検索します。ZIP 内の ZIP と暗号化 ZIP は対象外です。
- ZIP の内部パスを一覧・レポートに表示し、同じファイル名が複数のフォルダーにあっても出力画像を区別します。一覧から除外した ZIP 内のファイルは検査しません。
- 全 32 テストと Clippy・整形チェックが合格しました。新規入力テストでは、フォルダーと ZIP の混在、重複追加、無圧縮・Deflate、個別除外、レポートと画像の出力を確認しています。GUI の実操作確認はユーザー側で行います。

## 0.2.2 の変更

- 「すべてクリア」で検査対象一覧、選択状態、検査履歴、結果リンク、進捗・経過時間を初期化できます。検査中はボタンを無効にします。
- クリアランス・保存先・自動表示の設定と、保存済みレポートは保持します。

## 0.2.3 の変更

- バージョンタグのpushで、Windows上のテスト・整形・静的解析、exeのビルド、チェックサム検証、GitHub Releasesへの公開を自動実行します。
- 通常のブランチpushは公開対象にせず、公開済みリリースは上書きしません。手動実行による公開なしのビルド確認にも対応します。
